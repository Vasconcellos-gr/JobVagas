# Buscador-Vagas

## Estilos do frontend

As páginas carregam as folhas nesta ordem: Normalize e Skeleton CSS 2.0.4
locais em `frontend/css/vendor/`, estilos compartilhados e tokens em
`frontend/css/global.css`, e componentes/estilos das páginas em
`frontend/css/style.css`. Não é necessário instalar pacotes nem acessar uma
CDN para carregar os estilos.
